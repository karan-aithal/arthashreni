# ADR-0002: uv for environments and lockfile

Status: Accepted, 2026-11-11

## Context
Need reproducible installs. `uv` 0.12.0 is installed.

## Decision
`pyproject.toml` + committed `uv.lock`. Install with `uv sync`; run with `uv run`. Python pinned via `.python-version` = 3.12. Dependency licences checked when added (MIT/BSD/Apache/Unlicense/PSF preferred; no AGPL in the core).

## Consequences
One tool for venv, lock and run. Plain `pip install -e .` remains possible as fallback.
