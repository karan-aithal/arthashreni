# ADR-0017: Leftover-cash default pending IPS

Status: Accepted as labelled assumption, 2026-11-11. Replaced by the investor's IPS choice once approved.

## Decision
Per B2: each month opens at the configured budget; leftover money moves to `cash_reserve`; it does not raise the next month's budget. Sale proceeds and dividends go to the reserve. Reserve use needs its own approved line. Every report states "Leftover-cash rule: default assumption (IPS not approved)".
