# ADR-0012: Local single-user authentication

Status: Accepted, 2026-11-11

## Decision
- API binds to `127.0.0.1` only; binding elsewhere requires an explicit config flag and logs a warning.
- One local user created by `arthashreni user init`. Password hashed with Argon2id (`argon2-cffi`). Session cookie: random 256-bit token, `HttpOnly`, `SameSite=Strict`, server-side session table, 12-hour expiry. CSRF: same-site cookie plus a header token for state-changing requests.
- No broker credentials exist anywhere in the system (A3.3).

## Consequences
Adequate for a local tool; not designed for network exposure.
